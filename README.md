# Projeto Promoções SLS

Este repositório contém o código-fonte do projeto colaborativo **Promoções SLS**, desenvolvido pela turma LP2 de Programação em WEB (HTML, CSS e JS).

## 🎯 Objetivo Geral

Desenvolver uma plataforma web acessível, intuitiva e colaborativa, destinada à comunidade de São Lourenço do Sul, com o propósito de promover a economia familiar por meio da divulgação, pesquisa e comparação de preços, ofertas e promoções disponibilizadas pelo comércio local. A iniciativa busca auxiliar os consumidores na tomada de decisões de compra mais conscientes e econômicas, especialmente na aquisição de produtos essenciais à subsistência, contribuindo para a redução das despesas familiares, a valorização do comércio lourenciano e o fortalecimento da economia local.

## 📋 Objetivos Específicos

1. Facilitar o acesso à informação: disponibilizar ofertas e preços de produtos comercializados nos estabelecimentos locais.
2. Promover a economia familiar: permitir a comparação de preços entre diferentes estabelecimentos, identificando as opções mais vantajosas.
3. Estimular o consumo consciente: auxiliar as famílias no planejamento de suas compras, priorizando produtos essenciais e o melhor custo-benefício.
4. Fortalecer o comércio local: proporcionar maior visibilidade aos estabelecimentos comerciais de São Lourenço do Sul.
5. Incentivar a participação comunitária: permitir que consumidores e comerciantes compartilhem ofertas e informações atualizadas sobre preços.
6. Promover a inclusão digital: oferecer uma ferramenta gratuita, acessível e de fácil utilização para diferentes perfis de consumidores.

## 📁 Estrutura de Pastas

A estrutura base do repositório deve ser rigidamente mantida por todos os alunos. Cada um deverá organizar os arquivos referentes ao seu módulo dentro das respectivas pastas:

```text
promocoes-sls/
├── index.html        # Página principal
├── pages/            # Páginas HTML dos módulos
├── css/              # Folhas de estilo (incluindo o geral.css)
├── js/               # Scripts JavaScript
├── img/              # Imagens e ícones
└── database/         # Arquivos de banco de dados/integração
```

## 🚀 Fluxo de Trabalho (GitHub)

1. Clone o repositório para sua máquina local.
2. Crie uma *branch* para o seu módulo (ex: `feature/luis-home`).
3. Desenvolva seu código respeitando a estrutura de pastas e o CSS global.
4. Faça o *commit* das alterações e envie (push) sua *branch* para o GitHub.
5. Abra um **Pull Request (PR)** para a `main` solicitando a revisão do gerente do projeto (Anderson/Professor).
