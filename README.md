Este repositório contém o código-fonte do projeto colaborativo **Promoções SLS**, desenvolvido pela turma LP2 de Programação em WEB (HTML, CSS e JS).

## 🎨 Padrão Visual do Projeto

**Importante:** Nenhum aluno deverá criar uma identidade visual completamente diferente da dos demais colegas. Todos deverão manter o mesmo cabeçalho, menu, rodapé, botões, estilo de cards, tipografia e padrão de espaçamento.

## 📁 Estrutura de Pastas

A estrutura base do repositório deve ser rigidamente mantida por todos os alunos. Cada um deverá organizar os arquivos referentes ao seu módulo dentro das respectivas pastas:

```text
promocoes-sls/
├── index.html        # Página principal
├── pages/            # Páginas HTML dos módulos
├── css/              # Folhas de estilo (incluindo o geral.css)
├── js/               # Scripts JavaScript
├── img/              # Imagens e ícones
└── database/         # Arquivos de banco de dados/integração
```

## 🚀 Fluxo de Trabalho (GitHub)

1. Clone o repositório para sua máquina local.
2. Crie uma *branch* para o seu módulo (ex: `feature/luis-home`).
3. Desenvolva seu código respeitando a estrutura de pastas e o CSS global.
4. Faça o *commit* das alterações e envie (push) sua *branch* para o GitHub.
5. Abra um **Pull Request (PR)** para a `main` solicitando a revisão do gerente do projeto (Anderson/Professor).
